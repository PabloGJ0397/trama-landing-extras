# trama-landing-extras

🇪🇸 [Versión en español más abajo](#es-versión-en-español)

HTML/CSS/JS extras for the landing page of **Trama**, a shared event agenda for community groups, associations and neighbours. Built for the Business Management Systems (SGE) course, 2nd year of DAM (Multiplatform App Development), 2026.

🔗 **Published landing page:** https://battle-lunaria-9bf.notion.site/TRAMA-420a38e76acd809a93f6e968389af1b9

The landing page itself is built in Notion. The files in this repo are embedded into it via Notion's `/embed` block and served through GitHub Pages.

## Contents

| File | Use in the landing page |
|---|---|
| `cabecera.html` | Animated header |
| `demo.html` | Interactive demo calendar (filters by topic and group, clash warning) |
| `dynamic_braid_vectors/trenza-perpetua-seis-transparente.html` | Animated thread strip in the hero section |
| `dynamic_braid_vectors/cosido-*.html` | Animated stitch lines that separate sections |

Everything is self-contained HTML with no dependencies.
